# Very Three

Piggy、4010、Joey 三个男生的 3D 小家。Three.js 原创几何模型组成共享客厅、北侧 Piggy、西侧 4010、东侧 Joey 和南侧玄关。保留彩虹细节、九个上传相框、个人房间精装、玩偶日常动作与 15 秒原创房间音乐。

## 本地运行

Node.js 20 或更新版本，双击 `Start-Mac.command`，或在项目目录执行 `npm run dev`。不需要安装项目依赖；浏览器打开 http://localhost:5173/ 。编辑 `dist/` 自动刷新，Control + C 停止服务。

## 云端接入版本

此版本使用 Supabase 邮箱 + 密码登录，代替旧版 xiaosi 前端暗号。前端仍部署到 GitHub Pages，数据库、登录和私有图片桶由 Supabase 托管。只接受后台绑定的三个账号，每人只编辑自己的名字、心情、卧室和相框；留言/合照只能作者删除，见面计划共同维护。

请先完成 [Supabase 初始化步骤](supabase/README.md)，再合并此分支到 main 上线。脚本不包含账号密码或服务器管理密钥，网页仅使用 Publishable key。SQL 脚本创建的 Row Level Security 才是数据访问控制。

同步间隔十秒，恢复页面可见时立即同步。失败时提示重试，不把未保存内容报告为成功，不自动回退写入本地。图片先压缩为 JPEG，再上传到私有桶；每个相框独立更新，共享相册最多八张。

## 旧本地内容与设备偏好

保留 `three-at-home-v1`，不清空旧照片和留言、不自动上传或替换云端内容。旧内容可在旧版本中查看，后续按需要重新上传；云端版本的共享内容以数据库为准。每次打开默认黑夜，当前访问可手动切换或启用系统外观；留灯和音乐静音保留在当前设备。

自动外观跟随系统深色/浅色，手动模式保留；减少动画设置会停止玩偶与黑胶的连续动作。进入卧室播放一次 15 秒原创风格音乐，切房、回客厅/全景或隐藏页面即停止，右上角仅保留静音图标。

## 扩建与沉浸视角

保持同一套连通户型和家具比例。Piggy 的宽房间地面增加约 46%，电脑区向左展开；4010 的长房间地面增加约 41%，听音阅读区向前延伸；Joey 的 L 形卧室增加约 40%，衣架、穿衣镜和玩偶移入独立换装翼。客厅地面增加约 38%，前侧留活动毯和通行空间。地台按新轮廓生成，房间地板不重叠。

全景保留欢迎页，点击客厅或卧室后自动收起介绍区，模型使用更大的画面，保留顶部五个空间入口和房间手记按钮。手机进入空间后减少页面高度和上部留白；全景按钮恢复原来的欢迎视图。云端数据、原有九个卧室相框、客厅四个大回忆相框和系统外观功能保持不变。


## 人物串门与四张照片墙

点击「去串门」控制当前账号对应的玩偶，原来坐着的角色会暂时隐藏。电脑用 WASD / 方向键，手机用方向按钮，或点击地面自动寻路。人物通过门洞并避开墙体、家具和地台边缘，跨房间时切换镜头和 15 秒房间音乐。可切到全景规划路线，也可点「找到我」回到人物所在房间。打开详情、切换后台和窗口失焦会停止当前移动；「结束串门」恢复角色的日常位置。尊重减少动画设置，但方向操作仍可用。

这一版位置仅在当前浏览器内使用，不写入数据库，不是实时多人同屏。

客厅照片墙改成四张大相框，显示共享相册最近四张照片，旧照片仍保存在相册。扩大单张显示面积，同时保留房间九个上传相框。顶部手记入口改成高对比卡片按钮，适配系统深色和手机布局。

## 小猫

客厅的小猫会在猫窝睡觉、绕开家具散步。点击小猫可以摸头：它会抬头、显示爱心并轻轻喵一声；正在串门时，摸头后它会跟随约十八秒，也会靠近移动的人主动跟一会儿。夜间更常回窝休息。顶部静音按钮同时控制房间音乐和喵叫，切到后台立即停止声音。小猫行为暂为当前页面本地状态，尚未同步到数据库。

客厅新增奶油棕色短腿小狗及软垫，会休息、散步和回窝。点击小狗或“摸摸小狗”会抬头摇尾巴。和小猫一样，行为暂为当前页面状态。

## 庭院与种植

北侧门洞接入庭院，点击庭院入口聚焦；串门时点击地面可以走进去。三块个人花圃各有三个种植位，支持向日葵、绣球、薄荷，植物在模型中显示播种、发芽、长叶和开花四阶段。

已有项目需在 Supabase SQL Editor 执行一次 `supabase/garden.sql`。迁移可重复执行，不删除旧数据；完成后刷新网页即可播种。未执行时仍能浏览庭院，种植面板显示准备中，不写入本地假数据。每人只能在自己的花圃播种，三位家人均可浇水；正常约十二小时长成，每次浇水提前一小时，四小时冷却。生长使用数据库记录的时间，离线也会继续，植物不会枯死。页面沿用十秒轮询，同步种植状态。

## 房间布置
Piggy 房间现在在南侧，庭院在北侧。执行 `supabase/decoration.sql` 后，可用“布置我的房间”更换墙面、地板与地毯颜色，摆放盆栽、落地灯、小凳子、边桌、坐垫和小地毯；支持点选移动、旋转、收回、撤销与恢复默认。确认摆放后点击保存，其他家人每十秒同步。编辑期间暂停人物与宠物动作；退出放弃未保存改动。数据库只允许当前房主保存，并检查版本以防多设备覆盖。

## 互动家具
摆放并保存街机、鱼缸、望远镜后，退出布置，点击模型即可打开互动弹窗。街机是六十秒接星星挑战，手机滑动或键盘方向键；切后台会暂停。鱼缸能投喂、改名与换色，三人可帮忙投喂，十分钟冷却。望远镜可拖动原创星空、查看北斗七星和猎户座、触发流星和写愿望。已有项目执行 `supabase/activities.sql` 启用共享成绩、鱼缸设置、投喂和愿望；原有装修、相框和种植保持不变。

## 四位家人与自主日常
Zakery 与 Joey 共用卧室，独立成员账号。执行 `supabase/zakery.sql` 并在 Authentication 创建、绑定账号。未绑定时可先看到模型，不能用未绑定账号进入。四位角色在未被操控时会随机散步、坐椅子、躺床、去客厅陪猫狗；仅当前浏览器运行。接管自己的角色后暂停其自主活动，退出后继续，其他角色保持日常。

## A 户型与实时人物避让
三间卧室排列在北侧，共用独立走廊，南侧客厅直通前庭院。保留房间内的装饰坐标与云端数据，不需 SQL。相遇时根据实时位置避让，手控角色优先；自主角色侧移或退让，路线拥堵后绕行。接管人物及异常位置恢复时选择可通行且未被占用的位置。

## 等面积卧室与客厅直达
三间卧室采用相同的 10.2×12.6 模型尺寸，取消走廊；客厅与卧室之间为同一整面分隔墙，开三个门，门扇常开。卧室窗户统一放到北侧外墙，不再开向相邻卧室；墙面装饰避开窗户和门洞。现有云端数据和房内装饰坐标保持，不需数据库迁移。

## 家具分组与共享墙修复
移除旧窗帘残件；电脑、唱片、专辑及换装区按完整模型分组移动，避免椅背、桌腿和装饰错位。侧墙摆放通过家具边界检查。Joey 门位调整到直达通道，共享分隔墙统一暖米灰色并排除个人房间配色。无需 SQL。
